# 快捷键

快捷键与原生菜单 accelerator 保持一致。macOS 使用 ⌘/⌥/⇧；Windows/Linux 将 ⌘ 映射为 Ctrl。

## 全局

| 快捷键 | 作用 |
|---|---|
| ⌘ 1 | 打开提交图谱 |
| ⌘ P | 聚焦仓库切换器 / 仓库搜索 |
| ⌘ F | 聚焦提交搜索 |
| ⌘ ⇧ F | 立即 Fetch |
| ⌘ ↵ | 打开暂存与提交 |
| ⌘ B | 收起 / 展开侧栏 |
| ⌘ / | 切换深色 / 浅色主题 |
| ? | 显示快捷键面板 |
| Esc | 关闭抽屉、弹窗与叠加层 |

## Diff

| 快捷键 | 作用 |
|---|---|
| W | 切换宽屏 Diff |
| ⌘ + / ⌘ - | 放大 / 缩小 Diff 字体 |
| ⌘ 0 | 恢复默认 Diff 字号 |

## 原生菜单（macOS）

| 菜单 | 快捷键 |
|---|---|
| 文件 → 新建仓库… | ⌘ N |
| 文件 → 打开仓库… | ⌘ O |
| 文件 → 克隆仓库… | ⇧⌘ O |
| 文件 → 关闭仓库 | ⇧⌘ W |
| 偏好设置… | ⌘ , |
| 仓库 → Fetch | ⇧⌘ F |
| 仓库 → Pull | ⌥⌘ P |
| 仓库 → Push | ⇧⌘ P |
| 仓库 → Commit | ⌘ ↵ |

Web 浏览器模式无原生菜单；页面内快捷键兜底生效。

## 审查评论

| 操作 | 说明 |
|---|---|
| 点击行号（树预览 / Diff） | 打开或收起该行的评论区 |
| 圆点标记 | 行号旁的圆点表示该行已有评论线程 |
| 发送输入框 | Enter 发送评论 / 回复 |
| ✓ 图标 | 标记或取消「已解决」 |
| 发布本地草稿 | 托管面板 PR 详情中一键发布（仅锚定在 PR 源分支上的线程） |
